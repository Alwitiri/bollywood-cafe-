# Bollywood Cafe Ooty, website

Single-page website for **Bollywood Cafe**, a small tea & coffee shop on Segur Rd, Ooty (4.9★, #4 of 136 coffeehouses in Ooty).

- `index.html`: the whole site (HTML + CSS + JS; GSAP animations loaded from cdnjs)
- `BUSINESS_ANALYSIS.md`: business strategy and pain-point analysis behind the design

## Run locally
```bash
python -m http.server 8765
```
Then open http://localhost:8765.

## Deploy
Static site: no build step, publish directory is the repo root.

- Replace the Unsplash placeholder photos with the cafe's own photos
